# Pi BTW

Adds a side-question workflow so a small question can be answered without redirecting the main task. Optional; it changes how you interact with a session but does not change the model provider.

- Package: `pi-btw`
- Version represented here: `0.6.0`
- Pi package entry: `npm:pi-btw@0.6.0`

Add the package entry to the `packages` array in `~/.pi/agent/settings.json` (Windows: `%USERPROFILE%\.pi\agent\settings.json`), preserve other entries, and restart Pi. Read upstream documentation for command syntax and current behavior.
