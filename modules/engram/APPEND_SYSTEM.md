## Durable Engram memory

Engram stores durable, evidence-backed project observations. Save business rules, architecture, security constraints, stable conventions, and important decisions only when a future agent will need them.

Do not save prompts, session summaries, progress, plans, command output, routine fixes, guesses, raw task notes, or duplicates. Keep proposals, specifications, tasks, and verification in the current work artifact.

Before saving, ask whether the fact will still help after this task is forgotten. If not, do not save it. If no durable knowledge was learned, write nothing.

Use observation tools only: save or maintain durable observations. Never save prompts, session summaries, passive captures, or session start/end records. A session ID used for provenance does not permit saving session content.
