# Pi Web Access

Adds web search and page-fetching capability to Pi. Optional: install it only if you want web research available in your sessions.

- Package: `pi-web-access`
- Version represented here: `0.30.0`
- Pi package entry: `npm:pi-web-access@0.30.0`

Add the package entry to the `packages` array in `~/.pi/agent/settings.json` (Windows: `%USERPROFILE%\.pi\agent\settings.json`), preserve other entries, and restart Pi. Consult the upstream package README for provider/API configuration and current version notes. Web access does not imply browser automation; use the Playwright skill for that workflow.
