# Diagram Design

Creates or revises technical and product diagrams, including architecture, flows, data models, deployment, and related visualizations. Invoke the skill when a diagram is part of the work; it is not an automatic project scan.

Copy this folder to `~/.pi/agent/skills/diagram-design` (Windows: `%USERPROFILE%\.pi\agent\skills\diagram-design`). The bundle includes its `SKILL.md`, examples, references, and helper scripts. It is from [cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design), licensed under MIT. The included license and third-party notices cover the bundled material. Review upstream updates intentionally and retain these notices when redistributing.
