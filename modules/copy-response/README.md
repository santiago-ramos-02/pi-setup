# Pi Copy Response

Adds a command for copying an assistant response. Optional convenience for terminal workflows.

- Package: `pi-copy-response`
- Version represented here: `0.3.5`
- Pi package entry: `npm:pi-copy-response@0.3.5`

Add the package entry to the `packages` array in `~/.pi/agent/settings.json` (Windows: `%USERPROFILE%\.pi\agent\settings.json`), preserve other entries, and restart Pi. Check upstream documentation for supported clipboard backends and terminal-specific behavior.
