# Context7 for Pi

Provides library and framework documentation lookup from Pi. Use it when implementation depends on current library APIs, not as a general-purpose web browser.

- Package: `@upstash/context7-pi`
- Version represented here: `0.1.2`
- Pi package entry: `npm:@upstash/context7-pi@0.1.2`

Add the package entry to the `packages` array in `~/.pi/agent/settings.json` (Windows: `%USERPROFILE%\.pi\agent\settings.json`), preserve other entries, and restart Pi. Follow the upstream package's setup for any required Context7 credentials or configuration; do not put secrets in this repository.
