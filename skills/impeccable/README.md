# Impeccable

Provides frontend design and implementation guidance, including interface critique, responsive behavior, accessibility, and visual polish. It is optional and most useful on tasks that change a user interface.

Copy this folder to `~/.pi/agent/skills/impeccable` (Windows: `%USERPROFILE%\.pi\agent\skills\impeccable`). The `SKILL.md`, reference material, and helper scripts are the useful parts Pi can load. The bundle also contains Codex-format agent metadata; Pi does not automatically turn those files into Pi subagents.
