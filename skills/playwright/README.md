# Playwright

Provides instructions for browser automation and visual verification using Playwright CLI. It can help agents exercise real pages and inspect responsive/overflow behavior; it does not itself install a browser or guarantee every machine has the required browser dependencies.

Copy this folder to `~/.pi/agent/skills/playwright` (Windows: `%USERPROFILE%\.pi\agent\skills\playwright`). Install the CLI separately using the documented package version `@playwright/cli@0.1.21` and follow Playwright's instructions for installing browsers and system dependencies. See `SKILL.md` and the included references. This snapshot includes license and notice files; retain them when copying or redistributing.
